# Limit Theorems
Let $X_1,X_2,...$ i.i.d random vectors. Set $\bar X_n=\frac{1}{n}\sum^n_{i=1}X_i$

## LLN - Law of Large Number
If $\mathbb{E}[X_i]>\infty, \mathbb{E}[X_i]=\mu$ then $\bar X_n\xrightarrow{p}\mu$ almost surely.

## CLT - Central Limit Theorem
If $\mathbb{E}[X]=\mu\in\mathbb{E}^d, Var(X_n)=\Sigma$ (finite). Then $\sqrt{n} (\bar X_n-\mu)\rightsquigarrow \mathcal{N}(0,\Sigma)$

#Convergence theorems
## Continuous mapping
Suppose $f:\mathbb{R}^k\rightarrow\mathbb{R}^m$ is "almost surely continuous"
- $X_n\rightsquigarrow X\implies f(X_n)\rightsquigarrow f(X)$
- $X_n\xrightarrow{P} X\implies f(X_n)\xrightarrow{P} f(X)$
- $X_n\xrightarrow{as} X\implies f(X_n)\xrightarrow{as} f(X)$

## Slutsky 
Assume $X_n\implies X, Y_n\xrightarrow{p} c$. Then:
- $X_n+Y_n\implies X+c$
- $X_n\cdot Y_n\implies cX$
- $X_n/Y_n\implies X/c$ if $c\neq 0$

## Delta method
If $\sqrt{n}(X_n-\mu)\implies \mathcal{N}(0,\sigma^2)$ and $f(x)$ diff at $x=\mu$. Then $\sqrt{n}(f(X_n)-f(\mu))\implies \mathcal{N}(0, [f'(\mu)]^2\sigma^2)$

Multivariate case: $\sqrt{n}(X_n-\mu)\implies \mathcal{N}_d(0,\Sigma)$
